# iOS 热水异常诊断候选 build 37

日期：2026-10-29。此候选仅保存在本地，尚未发布正式版。

## 已知问题与修改

测试者反馈：短暂出水后停水；结束时提示水控未返回使用中状态；重启后又显示已授权。录像和代码可确认“结束检查失败后，临时错误未持久化”的展示缺陷，不能仅凭录像确定实际停水原因。

- 对照本机保存的官方客户端蓝牙代码，官方授权成功后保留连接、完成结束后清理；原 iOS 在成功授权后立即断开。候选改为成功授权后保留 BLE、失败和结束后释放；只读检查确认设备仍在使用中时也保留连接。该差异是值得验证的原因，不能据此宣称立即停水根因已确定。
- 当结束检查返回非使用中回复时，保留会话并保存待核对标记。重新启动仍显示待核对，不以本地 active 阶段覆盖设备观察结果。
- 不改变未使用中时禁止发送结束指令、禁止结算的保护。
- 在设置的高级故障排查中增加“只读检查本次水控状态”，固定连接原会话设备，仅发送读取指令，不获取新授权、不关水、不结算。收到其他设备编号时拒绝，不改原会话。
- 增加本机诊断环形日志，最多 200 条；记录操作时间、存储阶段、蓝牙步骤、发送命令类别、回复类别和字节数、固定错误码。
- 导出报告包含 App 版本、构建号、机型与系统版本；不包含学校账号、密码、Token、平台密钥、宿舍、蓝牙标识、设备编号、原始帧或费用。
- 设置页显示完整版本和构建号，便于核对测试者包。

## 给测试者的操作

先确认现场与官方记录。覆盖更新 build 37，保留现有配置和会话，不卸载。若仍有待核对会话，在水控附近打开“设置 → 高级设置与故障排查 → 只读检查本次水控状态”，等待完成后点“导出热水诊断”，通过系统分享发回。无待核对会话时这项只读检查不可用，直接导出也可，但不会补回旧版本未记录的设备回复。

不要求连接 Mac。新日志只覆盖更新后的操作，不把旧问题的原因推断为已经确认。
