# 首次连接热水

> Beta 2（iOS build 36 / Android alpha22）提供自动接入流程。版本仍处于测试阶段；真实热水授权、出水与结算未完成本轮验收。

1. 在「设备 → 学校账号」使用本人学校账号完成官方登录。
2. App 同步校园卡，读取学校门户登记的宿舍地址，并直接向热水平台核对本人身份。
3. App 按学校登记宿舍匹配热水位置和水控清单；请核对房间和设备信息后保存。Android 可在热水页只读扫描附近水控，开始前也会再次核对设备编号。
4. 电表按校园目录自动匹配。目录中有同名公寓时，确认一次公寓位置；无法唯一匹配时可手动选择。

Beta 2 完整安装包已包含平台通用配置，首次使用不需要抓包、导入 JSON、连接开发者电脑或访问项目接入服务。学校资料没有登记完整宿舍时，仍需手动选择；不能猜测设备。

## 连接方式与隐私

学校登录、校园卡和电表直接访问学校系统；热水身份、宿舍列表、授权和结算直接访问热水平台。蓝牙由手机与附近水控通信。不依赖本项目的 Cloudflare 服务、开发者电脑或家庭网络；学校和热水平台的网络仍需正常。

学校密码与验证码只在官方认证页输入。手机保存本人的登录与水控配置；学校提供的身份交接信息仅用于官方热水平台核验。此直连方案不把校园会话交给本项目服务器。

平台共用签名参数随安装包提供。它不是个人校园账号，但持有安装包的人可能提取它；钥匙串、加密存储或混淆不能保证参数对手机持有者永久保密。公开源码使用占位说明，本机打包时单独注入通用参数，不打包个人会话、姓名、宿舍、控制器或签名证书。平台协议变更时可能需要包含配置迁移处理的新版 App。

## 旧版本升级

正常覆盖升级保留原有登录、用水与洗衣记录、电表配置和缓存。已有直连配置继续使用。旧在线配置仅在无未决记录、且官方接口核对本人身份一致后转换；失败时不强行覆盖。有未决在线记录时先在原版核对完成，再升级，不能靠切换路线或重试绕过。

真实授权、出水和结算可能连接现场设备并产生费用；本轮未执行真实交易。遇到状态不明时，不要重复开始或结算，先查看 App 保存的会话和官方结果。

「备用接入方式」仅保留给迁移和排查，正常首次设置不依赖它。个人完整配置和抓包不得公开。无签名 IPA 仍需自行签名；直连不改变 Apple 的安装要求。
