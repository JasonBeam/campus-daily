# 故障排查

| 现象 | 先检查 | 下一步 |
| --- | --- | --- |
| App 无法安装或签名失效 | Xcode Team、Bundle Identifier、设备开发者模式、签名期限 | 在本人 Xcode 重新签名，保留业务记录；不要向作者索取个人签名包 |
| No such module AlipaySDK / SDK 路径缺失 | 官方依赖是否放在构建文档要求的路径 | 核对来源、版本和哈希，再生成项目 |
| 校园余额显示上次值 | 查询时间、网络、校园登录有效期 | 先看官方校园入口是否正常，再更新本机配置；失败不是余额为零 |
| 宿舍为空或绑定不唯一 | buildingID、dorm_room 与本人实际绑定 | 在官方入口确认唯一目标，不自动猜宿舍 |
| U净登录失效 | 本人官方账号状态、token 有效期 | 本人在官方入口登录，在本机更新配置，不公开请求头 |
| 机器暂不可用 | 现场是否有人使用、官方入口状态、当前查询时间 | 等设备可用后再看，不靠反复创建预约探测 |
| 热水连接失败 | 解锁、蓝牙权限、距离与设备匹配 | 不修改设备身份碰运气；未知授权阶段不要再次开始 |
| 已授权但没有出水 | 页面提示及现场实体出水键 | 按现场操作核对；App 无法检测水流 |
| 结束结算结果不明确 | 现场是否已停水、官方账单、本机保留阶段 | 不重复提交或卸载清记录，先核对现场与官方入口 |
| 支付宝未打开或授权未完成 | 支付宝安装、本人授权、网络、订单状态 | 不拼接或复用旧付款链接，不反复下单 |
| 支付完成但 App 状态未更新 | 官方支付宝账单与 U净订单 | 只读刷新核对；跳转回调本身不是扣费和机器运行证明 |
| 订单待确认 / 取消待确认 | 官方订单与本机状态 | 保留记录，不重复 POST，不宣称自动退款或停机 |
| 学校登录页打不开 | 网络、学校门户状态、是否仍停留在官方 HTTPS 页面 | 重新从设置进入；不要把学校密码或登录 state 发给他人 |
| U净收不到验证码 | 手机号、运营商短信与官方服务状态 | 60 秒后可由本人重试；不把验证码或 token 发到公开渠道 |
| 洗衣机二维码识别失败 | 是否为 U净机身码、照片是否只含一台机器、权限是否允许 | 对准机身二维码或换一张清晰照片；已有未结束订单时先核对订单 |

反馈前按隐私文档脱敏。公开 Issue 不上传 HAR、完整错误响应、配置、付款 URL 或设备二维码。
