# Android alpha23 同步 iOS 修复

日期：2026-10-29。版本 0.2.0-alpha23-debug / versionCode 25，仅本地测试候选。

## 变更

- 授权成功后保留 BLE 连接；结束时复用同一已就绪连接，失效连接在下一次连接时清理。授权失败与结束后释放连接。
- 水控未返回使用中时，持久保存待核对状态；重启继续显示待核对，不发送关水或结算。
- 已有会话可只读检查原水控状态，不请求新授权、开关水或结算。
- 最多 200 条脱敏诊断事件，可通过系统分享面板导出。仅保存固定事件、阶段、命令类别、回复类型及长度；不保存账号、地址、机器编号、密钥或原始帧。分享 FileProvider 仅开放诊断缓存目录。
- 校园卡、电费查询继续使用 ViewModel 任务，不随下拉控件销毁而取消。请求取消正常传播，不再显示断网错误或继续查询下一接口。
- 自动刷新间隔只从成功计算；失败、取消可立即重试，保留旧余额和时间。账号、电表分别计算刷新间隔。
- 保留现有账号、宿舍、余额缓存、交易和旧会话字段兼容；不增加重置入口。

## 本地验证

- assembleDebug、assembleDebugAndroidTest、72 项 JVM 单元测试通过；lint 无错误，仍有 36 条警告。
- API 36 Android 模拟器上通过 7 项 instrumentation 测试，覆盖失败/取消后保留缓存与立即重试、授权保留连接和单次结束结算、诊断分享目录限制、只读入口及待核对 UI。
- 蓝牙和结算测试均使用模拟实现，无真实水控或交易。模拟器测试不能证明实体 BLE、后台保活或现场出水效果。
- APK ZIP 完整性、平台资源字段白名单检查通过。包名仍为 com.beamjason.xiaorichang.debug，签名与 alpha22 相同，可覆盖升级。
- 交付文件：Downloads/CampusDaily-0.2.0-alpha23-debug.apk，附 SHA-256 校验文件。
- 未连接安卓实体手机，未发布、推送或打标签。待用户覆盖安装并现场确认首页刷新、用水及结束行为。

短暂出水后停水的实际原因仍未确认；本版连接生命周期与官方客户端保持一致，效果需实机复测。
