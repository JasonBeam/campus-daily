# 微信充值入口链接复用错误修正（本地候选）

用户截图显示“此链接已被其他用户访问，你无法访问”。检查发现 iOS 与 Android 均硬编码了同一学校小程序生成的微信短链及对应 HTTPS 中转页。该链接此前仅在本人 iPhone 验证，不能据此认为可跨用户复用；具体限制和有效期尚未取得微信服务端证据。

移除两端共享短链与中转页，改为明确的微信搜索引导，以及用户主动复制“e广工商大办事大厅”名称。Android 通过微信主 App 的启动 Intent 打开微信，添加必要包可见性声明；未找到微信时提示手动打开。iOS 仅打开微信，不再进入页面就自动跳转。没有伪造新的小程序地址或承诺直达支付。

最近一笔洗衣金额与已确认的最近热水结算金额已有展示；完整学校热水及 U净历史账单仍未接入，不能把旧未决记录或余额差额当成消费金额。

仅修改本地源码，原工作区同步前逐文件核对基线并备份。未连接手机、未安装、未发布、未创建订单或充值。本修正未包含在原有 build55 IPA 中。

验证：iPhoneOS Release 构建通过；Android compileDebugKotlin 通过；git diff --check 通过。微信拉起、搜索、不同用户充值仍待实机验收。
