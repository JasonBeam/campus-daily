我把自己每天用的校园服务做成了一个 iPhone App。

原因很朴素：洗个澡、洗件衣服，每次都要找入口、进小程序、等跳转。校日常现在把校园卡余额、宿舍、热水和 U净洗衣放在一起，常用的数据直接看，常用机器扫一次码就能保存。

现在可以：
• 首页看校园卡和宿舍
• 蓝牙连接宿舍水控
• 用快捷指令开始洗澡、结束结算
• U净扫码绑定洗衣机
• 看空闲状态、程序、时长和价格
• 核对后前往支付宝

这几个动图是界面流程模拟，不是真实出水或支付的录像，重点是展示页面怎么走。

先把门槛说清楚：现在还不是所有人都能直接安装的成品。没有 TestFlight；GitHub 会放无签名开发 IPA，下载后还要用自己的 Apple 身份签名，免费 Personal Team 一般 7 天要重签。适合有 Mac、Xcode、自己的 Apple 账号，也愿意保护个人配置的同学试用。

另外，当前主要针对我实际使用的一种水控和本校环境，不代表所有学校、楼栋或设备都通用。首次热水配置仍有平台参数门槛，所以短期内更适合愿意自己编译、能看懂基础报错的人。

配置步骤也整理好了：学校官方网页登录 → 选择宿舍 → U净短信登录 → 扫码绑定洗衣机。GitHub README 里同时放了配置教程、构建签名、故障排查和可以直接交给 AI 的上手提示。后续我会继续处理更稳定的证书/分发方式；先别把学号、手机号、宿舍、二维码、配置或抓包往评论区发。
