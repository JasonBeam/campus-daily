# Native Clear / 03 原生清爽

用户确认第三套整体App设计语言。本轮更改首页、热水、洗衣与首次配置，使用系统中文与数字、原生分组背景、蓝色操作。

| Before | After | Why |
|---|---|---|
| 校园卡与电费分散在纵向大块 | 双余额放入同一分组，保留独立查询时间、异常和充值入口 | 快速比较，避免将旧缓存误当成新数据 |
| 点阵标题和英文小标签 | 系统字体、清晰中文、适配明暗主题 | 匹配选定的03方向 |
| 首页集中所有操作入口 | 日常／订单／设备三个原生Tab | 最近记录和个人设备更容易找到 |
| 热水开始和结束并列 | 按会话状态突出可用动作，操作区放底部 | 减少视觉干扰，保留既有状态限制 |
| 紧凑的洗衣费用行 | 金额单独突出，付款启动设备提示靠近按钮 | 付款前看清费用和行为 |
| 配置合并成两项 | 学校账号、宿舍水控、常用洗衣机三项进度 | 明确下一步，电表作为可选绑定 |

## 保留的行为

未更改WaterCore协议与交易逻辑、WaterModel/蓝牙状态限制、校园和洗衣账号存储、请求刷新节流，以及Widget/Shared的渲染和缓存。热水仍须在授权后按设备出水键，不能把已授权当作已经实际出水。洗衣创建、支付确认、未支付取消确认和结果核对保留。订单Tab只展示本机保存的最近记录，不声称支持完整历史查询。
