# Android 与 iPhone 页面校对

Android alpha3 的页面布局以 2026-10-27 安装在 iPhone 上的实际界面为参考。两端使用各自的系统组件，因此字体、图标和动效不会完全相同。

| 页面 | 校对内容 |
| --- | --- |
| 日常 | 余额顺序、金额位置、更新时间与底部导航 |
| 热水 | 房间信息、费用行、状态和底部操作 |
| 洗衣 | 设备信息、程序卡片与确认按钮 |
| 设置 | 分组列表、标题和常用操作入口 |

## 本地检查与隐私

对照截图、布局数据和构建日志保存在开发者本机，没有放入公开仓库或 Release。Android 预览使用示例余额和示例订单，按钮不会发出网络请求。真实校园账号、宿舍信息、设备标识及交易截图不随仓库发布。

alpha3 的页面检查覆盖 23 组尺寸、深浅色和字体场景，并检查了导航切换。此类检查只验证布局，不代表真实登录、蓝牙出水、结算、下单或付款已通过。

电表与宿舍匹配、校园网页登录等功能在 alpha3 之后继续更新；当前版本状态以[最新测试版说明](release-0.8.0-beta.1.md)为准。
