# 学校平台入口：双设备测试 2026-11-05

## 设备和结果

- 本人 iPhone 16 Pro Max（iOS 27.0.1）：在微信搜索并打开“e广工商大办事大厅”，实际进入学校首页；点击一卡通进入学校校园卡充值页，未填写金额、未创建订单。这证明微信搜索路径在该机可达，不证明不同微信账号都成功。
- iPhone 在微信搜索并直接访问 https://ecykt.gdbtu.edu.cn/ykt-view/hall ，显示“查询不到学校配置信息”，不能作为独立公共入口。未对该页面注入或复用其他账号的登录上下文。
- USB Android vivo V2405A：此前共享的微信桌面链接实际出现“此链接已被其他用户访问，你无法访问”，确认该链接不适合直接用于多人。不能从错误推断具体绑定手机、账号或其他机制。
- Android 由用户自行在微信内打开同一学校 H5 服务中心页面，也显示“查询不到学校配置信息”，与 iPhone 一致。
- Android 通过系统URL跳转测试此前基于学校已知首页路径的明文Scheme，微信返回“对不起，当前页面无法访问”；iPhone对此链接此前也出现相同失败。无法确定错误是学校配置、路径版本或平台策略中的哪个原因。

测试未为付款输入金额、创建订单或发起支付，也未使用他人登录凭据。没有安装build56，未验证本机历史订单、二维码识别或新包中的充值页面。两个设备或微信账号数量不构成所有用户的普适验证。

## 结论和建议

此前“微信中使用学校服务中心中转”的候选路径，目前无可用的独立学校配置和登录入口，不能作为已验证的公共跳转方案。共享桌面链接和所测明文Scheme均不可用于直接发布。继续使用微信搜索/学校官方小程序码作为当前可实施的入口；申请校日常自己的认证移动应用并接微信OpenSDK，或请学校签发可多人使用的正式URL Link/开放明文Scheme后，才有机会实现一键进入，均需分别实机验证。是否符合微信支付场景限制需另行确认。
