# 鸿蒙支付宝跳转测试：Android alpha24

用户反馈：校日常 Android APK 在卓易通中运行，洗衣下单后点击前往支付宝无法打开鸿蒙原生支付宝。当前没有设备日志，尚不能确定是卓易通跨容器限制还是付款参数类型等其他原因。

当 U净返回通过白名单检查的支付宝链接时，应用提供直接打开与浏览器中转两个手动选项。浏览器中转将已验证的支付宝 scheme 完整编码到 `https://ds.alipay.com/?scheme=...`；支付宝公开文档介绍了小程序 scheme 的这一形式，但没有证明它适用于此处的 WebView 授权入口或能够跨卓易通容器，因此此路径仅供实机试验。支付宝 HTTPS 二维码链接原样打开。SDK 签名订单仍走原有支付宝 Android SDK，不能使用该中转方式。

链接仅保存在当前界面的内存中，打开前检查账户和待付款订单；不会自动再次请求付款参数或自动切换渠道。返回后请在支付宝和 U净核对订单，打开页面不代表付款成功。

验证：干净构建、73 项单元测试和 lint 通过；Android 模拟器通过两项模拟 Intent 测试，覆盖原链接、中转编码及无处理程序时不自动切换。包名、版本、签名和压缩完整性已检查，签名与 alpha23 debug 一致。未在鸿蒙真机、卓易通或原生支付宝上测试，也未创建或支付真实订单。

实机操作：洗衣订单确认付款后选择“浏览器中转”，或选择“打开支付宝”；观察是否进入支付宝并核对订单。如果失败，请记录画面和操作步骤，不要分享完整付款链接或付款参数。
