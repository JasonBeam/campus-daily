# U净集成说明

当前实现围绕本人在广东工商职业技术大学使用的一台已配置机器，不宣称跨学校、跨模块兼容。

设备解析与程序查询使用 U净服务 `phoenix.ujing.online`，以本人有效凭据及本人机器配置请求；价格与程序读取当前响应，不硬编码历史报价。模块类型不同可能意味着不同启动方式，仅能查询或成功跳转不能推出机器已启动。

预约后先保存回执并核对设备、程序与金额；正常路径在「下单并前往支付宝」的明确确认后，读取后台签发的付款参数并打开允许的官方入口。只读支付渠道元数据有 45 秒内存缓存；真实付款参数、SDK 签名串和付款链接不预取、不缓存重放。创建结果不明确时保留记录并停在订单卡。

支付宝链接只复用后台签发内容，不构造交易或授权参数；解析限制 scheme、目标路径、授权域与回跳地址。支付宝确认、U净授权和网络依然存在，不能承诺完全没有页面跳转或广告。

本人已反馈修复后的实际跳转可用；扣费、机器启动、有效订单取消及连续路径速度没有独立完整实机验收。详见 acceptance.md。
