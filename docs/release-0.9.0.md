# 校日常 0.9.0

发布日期：2026-11-04

## 本次更新

- 新增正常洗衣／立刻洗衣选择。本人确认下单并支付后，返回 App 核对服务器已付款、订单及设备条件，再启动支持的洗衣机。
- 缩短付款回 App 后的查单等待，启动前合并重复查询；启动结果不明确时保留记录并继续查单。
- 洗衣完成提醒放进设置，支持开关、通知状态和十秒测试；已跟踪倒计时到零、回到 App 查到洗衣完成时可提醒。
- 设置重新分为账号与设备、日常使用和帮助，加入版本检查与更新提醒。
- 校园卡充值与电费充值合并为校园充值，通过学校官方微信服务办理。
- 保留机身按键停水后的待核对记录，水控忙时断开等待，下一次使用仍核验设备并获取新授权。
- Android 同步以上功能，版本为 0.3.0-alpha25（versionCode 27），仍作为测试包提供。

- Swift：133 项 XCTest 与 64 项 Swift Testing 通过，共 197 项。
- Android：93 项单元测试通过；模拟器布局与付款跳转策略共 3 项检查通过，静态检查通过。
- iOS：无签名 Release 和模拟器构建通过；本轮模拟器运行服务异常，未完成 iOS 新设置页的可视验收。
- 安装包：ZIP、版本、通用配置一致性与个人文件检查通过。Android debug 签名证书与上一公开版本一致。

## 使用范围与注意事项

- iPhone 早期候选的立刻洗衣、洗衣提醒已有用户实测成功；本次提速及新布局的构建与模拟器结果不能代替所有机型验收。
- Android 新增的立刻洗衣、提醒、热水恢复仍待真机验证。鸿蒙原生支付宝跳转尚未确认修复；可尝试页面提供的浏览器入口，仍失败时到官方 U净处理。
- 立刻洗衣需付款后回到 App；不承诺 App 被关闭或在后台时自动启动，也不会重复发送结果不明确的启动指令。机器需支持当前流程，其他启动前检查交由官方 U净完成。
- 通知取决于系统权限、订单数据和系统调度。倒计时是预计结束时间，实际完成以机器及官方订单为准。
- 热水设备空闲、断开蓝牙或校园卡余额减少，都不单独作为本次结算成功的证据。待核对旧记录会保留；完整历史消费流水尚未加入。
- 校园充值只是官方服务入口，不是校日常自有微信支付。是否支付、是否入账请在学校官方系统确认。
- 通用热水平台参数随安装包分发，可以被提取；公开源码与包不包含作者个人账号、宿舍、设备、交易记录或个人签名材料。请勿公开自己的诊断原始记录和账号配置。
