# 校园账号与宿舍信息

校日常使用学校官方登录页验证校园账号。登录后，App 会读取校园卡信息和门户中的宿舍地址，并保存在本机，用于显示余额和辅助宿舍配置。

## 使用步骤

1. 打开校日常的「校园登录与宿舍」。
2. 在学校官方页面完成登录和必要的验证。
3. 返回校日常，检查显示的校园卡和宿舍信息。
4. 设置热水时确认宿舍和水控设备；设置电费时手动选择电表。

App 不需要你把学校密码或验证码发给开发者。不要把登录页面截图、Cookie、校园令牌、学号或宿舍信息发到公开 Issue 或 AI 对话中。

## 当前范围

- 校园卡信息可在学校官方登录后同步。
- 门户宿舍地址可用于建议热水宿舍；保存前请核对本人信息。
- 宿舍电表暂时不能自动匹配，需要手动选择。
- 校园账号和会话由 App 在本机管理；更换账号时会清除不属于新账号的余额缓存与宿舍匹配结果。

遇到登录问题请看[配置教程](configuration.md)和[故障排查](troubleshooting.md)。本流程仅面向广东工商职业技术大学当前使用环境。
