# build27 · 充值登录态与同名水控识别

## 修改
- 充值不再直接套用小程序AuthMini跳转；使用当前账号向官方只读接口确认登录和所绑定校园卡，再给独立临时WKWebView提供官方网页会话。校验syscustid/custid归属，不选其他校园卡。充值URL不包含acc_token，保持原User-Agent；网页提示过期时提供学校官方重新登录入口。
- 蓝牙出现多个同名BT19-S时，按信号排序只读探测0xAA，再用已绑定宿舍的四字节硬件编号确认目标。信号只决定探测顺序，不证明归属。匹配后继续原授权前校验；无法读取时保留手动选择，明确读到其他编号则不自动使用。取消继续透传；结束结算保持原会话设备限制。
- 未修改充值金额/下单/支付逻辑；未假装绕过真正过期的登录。仅把登录流程桥接与到期反馈做完整。
