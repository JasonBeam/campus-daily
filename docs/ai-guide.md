# 用 AI 安装、配置和排错

AI 可以解释安装步骤、配置文档和错误提示。请先说明你使用 iPhone 还是 Android，以及遇到问题的页面和提示。

## 先选安装方式

- **Android：**从[下载页](https://jasonbeam.github.io/campus-daily/)下载测试 APK，按手机提示安装。Android 开发构建说明见[Android 指南](../platforms/android/README.md)。
- **iPhone：**下载的是无签名 IPA，需要用自己的 Apple 账号签名后安装。Safari 下载不会直接安装；步骤见[构建与签名](build-and-signing.md)。

## 可直接发给 AI 的提示

```text
我在使用校日常，设备是 [iPhone / Android]，系统版本是 [版本]，App 版本是 [版本]。
我想完成 [安装 / 校园登录 / 宿舍配置 / 热水 / 洗衣 / 错误排查]。
请先按 README、下载说明和配置教程给我一步一步的操作方法。
不要猜测接口、账号或设备信息。宿舍电表会尝试自动匹配；出现同名公寓时我需要确认位置。
不要要求我发送密码、验证码、Cookie、校园令牌、学号、宿舍、二维码、付款链接或私有配置。
涉及热水、订单或付款时，只帮助我核对步骤和提示；不要替我执行实际操作。
```

## 配置时记住

- 学校账号只在学校官方登录页输入。
- 校园卡与登记宿舍在学校登录后读取；电表可自动匹配，同名公寓需确认一次。
- Beta 2 首次连接使用安装包内的通用平台参数，本人登录后核验热水身份和宿舍，不需要抓包、导入个人配置或 USB 初始化。通用参数可能被提取；不要要求我发送配置文件。
- 完整热水授权、出水和结算未完成本轮验收。AI 只能解释文档与错误提示，不要代我开始用水、结算或重复操作。
- 洗衣使用本人 U 净账号。付款前核对设备、程序和金额。

大多数同学无需手动填写 JSON。旧版迁移和开发者字段见[配置教程](configuration.md)中的折叠说明。

## 排错时只提供脱敏信息

可告诉 AI：设备类型、系统版本、App 版本、出现问题的页面和完整错误文字。不要发送真实账号信息、请求头、抓包、配置文件、交易链接、设备二维码或私人截图。

```text
请根据我提供的脱敏错误提示，判断问题可能属于登录、网络、宿舍选择、蓝牙或版本兼容。
先给出不会产生费用的检查步骤。不要把旧余额当成最新余额，不要把失败解释为余额为零。
不要建议重复授权、付款、下单、取消或结算；结果不明确时请先让我查看官方页面。
```

构建成功、单元测试通过或看到页面，都不能证明现场水控、扣费、洗衣启动或付款已成功。实际操作由本人在现场核对并以官方结果为准。
