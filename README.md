# 校日常

**面向广东工商职业技术大学的非官方校园生活 App，提供 iPhone 与 Android 测试版。**校园卡余额、宿舍信息、热水和 U 净洗衣集中在一个 App 里，少在不同服务入口之间来回切换。

项目由个人开发，与学校、校园服务平台、U 净及支付宝无关；目前只围绕广东工商职业技术大学环境制作，不保证其他学校可用。

## 主要功能

- 在学校官方网页登录后同步校园卡信息，并读取门户中的宿舍地址。
- 查看校园卡余额和宿舍电量；**电表目前需要手动选择，尚不能自动匹配。**
- 连接本人确认过的宿舍热水水控，按页面提示完成授权与结束结算。
- 登录 U 净后保存常用洗衣机，查看状态、程序和价格，并核对订单信息。

## 开始前请留意

- 校园电表尚不能自动匹配，请按 App 提示手动选择。
- 公开安装包不含作者的热水平台私有参数；首次配置热水需要本人合法取得对应参数。
- 请使用本人校园账号和 U 净账号。学校密码、验证码和校园登录会话不要发给开发者或贴进公开 Issue。
- 测试记录、模拟器检查和安装成功不能替代真实设备与交易验收。热水出水、订单和付款请以现场设备及官方页面为准。
